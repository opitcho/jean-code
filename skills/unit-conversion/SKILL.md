# Unit conversion

1. Identify the quantity, the source unit, and the target unit.
2. Do not use conversion factors from memory. Read `reference/factors.md` with
   read_skill_file and use the factor listed there.
3. If a unit is not in the table, say so instead of guessing.
4. Answer with the formula you applied, then the result rounded to 3 significant figures.
