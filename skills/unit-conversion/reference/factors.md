# Conversion factors

Multiply a value in the "from" unit by the factor to get the "to" unit.

| from | to | factor |
|---|---|---|
| mile | kilometer | 1.609344 |
| foot | meter | 0.3048 |
| inch | centimeter | 2.54 |
| pound | kilogram | 0.45359237 |
| ounce | gram | 28.349523125 |
| US gallon | liter | 3.785411784 |

## Temperature (not a single factor)

- Fahrenheit to Celsius: C = (F - 32) * 5 / 9
- Celsius to Fahrenheit: F = C * 9 / 5 + 32
